# Локальные шрифты интерфейса

## IBM Plex Sans

- Файл: `IBMPlexSans-Variable.ttf`
- Источник: https://github.com/google/fonts/tree/main/ofl/ibmplexsans
- Лицензия: `IBMPlexSans-OFL.txt`

## Manrope

- Файл: `Manrope-Variable.ttf`
- Источник: https://github.com/google/fonts/tree/main/ofl/manrope
- Лицензия: `Manrope-OFL.txt`

Файлы подключены локально через `@font-face`, поэтому интерфейс не зависит
от доступности Google Fonts и продолжает работать без подключения к интернету.
